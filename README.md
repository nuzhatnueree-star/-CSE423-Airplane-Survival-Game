# 🐉 3D Dragon Survival Game

A 3D Dragon Survival Game developed using **Python and OpenGL** as part of the CSE423 Computer Graphics course.

## 🎮 About the Project

This game allows players to control a dragon and survive through various obstacles and dangerous situations in a dynamic 3D environment.

Players must avoid bombs, enemy attacks, and environmental challenges while navigating through the game world.

## ✨ Features

- 3D dragon movement and controls
- Dynamic weather effects (rain, snow, and storms)
- Day and night cycle
- Obstacles and bomb challenges
- Collision detection
- Enemy attacks and projectiles
- Ring-based targets and scoring
- Lives and countdown timer
- Shield functionality
- Multiple camera perspectives

## 🛠️ Technologies Used

- Python
- OpenGL
- PyOpenGL
- GLUT

## 🎯 Objective

Control the dragon, avoid obstacles and enemy attacks, and survive as long as possible while achieving the highest score.
