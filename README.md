# ✈️ Airplane Survival Game

A 3D Airplane Survival Game developed using **Python and OpenGL** as part of the CSE423 Computer Graphics course.

## 🎮 About the Project

The game challenges players to control an airplane and survive through different obstacles and dangerous situations. Players must avoid bombs, enemy attacks, and other environmental challenges while navigating through a dynamic 3D environment.

## ✨ Features

- 3D airplane gameplay
- Dynamic weather effects (rain, snow, and storms)
- Day and night cycle
- Obstacles and bomb challenges
- Collision detection
- Enemy attacks and projectiles
- Ring-based targets and scoring
- Lives and countdown timer
- Shield functionality
- Multiple camera perspectives

## 🛠️ Technologies Used

- Python
- OpenGL
- PyOpenGL
- GLUT

## 🎯 Objective

Survive as long as possible, avoid obstacles and enemy attacks, and achieve the highest score.
